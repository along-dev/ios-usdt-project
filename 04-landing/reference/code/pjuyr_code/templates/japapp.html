📱 iOS インストール手順
1. ダウンロードボタンをタップ
2. 構成プロファイルのダウンロードを許可
3. 設定 → 一般 → VPNとデバイス管理 へ移動
4. プロファイルをインストール
5. ホーム画面からアプリを開く
🤖 Android インストール手順
1. 「APK をダウンロード」ボタンをタップ
2. 「不明なソース」の警告が出たら設定で許可
3. ダウンロード完了後、インストールをタップ
4. アプリを開いてご利用ください
