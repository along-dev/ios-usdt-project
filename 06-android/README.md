## 二 · `tools/` —— 三段链（**需求 §1.7 的核心**）

| 文件 | 字节 | 角色 |
|---|---|---|
| **`bdecrypt.py`** | **4,277** | ★ **解密主入口**（**D0-C1 已修"分支错"**：`parts[1]` 分派 + `Counter` 修正）|
| **`bstage.py`** | 2,188 | 第 1 段 parser |
| **`bstage2.py`** | 3,029 | 第 2 段 parser |
| **`bstage3.py`** | 2,383 | 第 3 段 parser |
| `unpack.py` | 3,031 | 解包 |

### ★ 实测结论（**X4 的 U3，已验收**）

> **「三段解密可重复」** —— 3 轮解密**逐字节相同**，哈希稳定。
> ★ 且核实：**`bdecrypt.py` 的 parser 正确（slack=0）**；
> **`bstage.py` 的 parser 确为 fail**（**与 D0-C1 记录一致**）。

★ **本目录的 `06-android/tools` 文件数 = 5，行数 = 366**（**R3-C1 实测**）。
