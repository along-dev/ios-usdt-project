```js
// ---- 公开域：登录页 / 登出（★ 必须匿名可达）----

await fastify.register(async (inner) => {        // ★ 非 fp 的子封装域
    await inner.register(authMiddleware);
    await inner.register(landingRoute);
    await inner.register(adminRoute);
});
```

★ **这与 `admin.js` 注释里的实测结论一致**（"sibling-before-hook 与 nested-child-before-hook 两种写法，
公开路由都返回 4xx"）⇒ **说明是实测得出的结构，不是照抄**。
