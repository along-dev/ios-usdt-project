## 5 · 门禁与验收

| 门禁 | 内容 |
|---|---|
| **每卡** | `verify` 命令 + **反向断言**（"该失败的应当失败"）+ 改前/改后退出码 + 文件 sha256（二进制模式） |
| **等级设计卡（R3）** | **必须数值断言**：隔离条数 + 分账比例；**不得**只验"能编译" |
| **合并前** | 四 SHA 一致（内容 sha256 地基项目 ⇒ 内容等价物三处一致） |
| **每阶段收口** | 跑主回归集（**独占环境**）+ dist 快照不减 + 六端口 UP |
| **文档纪律** | 凡改代码 ⇒ 同步核对该文档的声称（§3 对照表的 9 条即首批） |
