## 2 · ★ 字段级细节（前端真实读取的字段）

### `/api/theme`
- **取值集合**：`{ blue, gold, neon, rose }`（`:498-521` 的 `data-theme` 属性）
- **默认值**：`"rose"`（`:910` `d.theme || "rose"`）
- **POST body**：`{ theme: name }`
- **POST 响应**：`{ ok: true, theme }`

### `/api/pixel`
- **GET 响应**：`{ pixel_ids: [...] }`
- **POST body**：`{ action: "add" | "remove", pixel_id: "<id>" }` ← ★ **注意是 action 而非覆盖**
- **POST 响应**：`{ ok: true, pixel_ids }`

### `/api/stats`
- **前端读取字段**：`total`、`today`、`clicks`
- 计算示例（`:724`）：`d.clicks / d.total * 100`
- ⇒ **必须含 `total` 与 `clicks`**，否则前端显示 `NaN`

### `/api/visits`
- **查询参数**：`page`、`per`（`:743` 拼接）
- **响应**：`{ total, rows: [...] }`
- **rows 每行字段**（前端渲染 + 已有硬样本）：
  `started_at`、`ip`、`country`、`city`、`device`、`browser` 等
- ★ **已有硬样本**：`E:\ios漏洞\_analysis\recon\visits_dump.json`（63,954 B）
  ⇒ `{ ok, page: 1, per: 100, total: 178, rows: [100 条] }`，**18 字段**

### `/api/apk/list`
- **响应**：`{ files: [...] }`
- ★ **`files` 元素结构（已实读 `:793-825` 提取）**：

| 字段 | 用途（前端） | 例 |
|---|---|---|
| `id` | **删除主键**（`:822` `deleteApk(${f.id})`） | 数字或字符串 |
| `original_name` | 文件名（`:803` `:817` `esc(f.original_name)`） | `"japapp.apk"` |
| `size` | 字节数（`:804` `fmtSize(f.size)`） | 8,324,931 |
| `uploaded_at` | 上传时间（`:804` `fmt(f.uploaded_at)`） | 时间戳/ISO 串 |
| `tg_file_id` | **可选**，Telegram 同步标记（`:798` `f.tg_file_id ? 'TG 已同步' : '仅本地'`） | 字符串或空 |

- ★★ **`files[0]` 被理解为「最新/当前使用」**（`:797` `const f = files[0]`；
  `:821` `i === 0 ? '当前使用' : '历史版本'`）
  ⇒ **后端必须按"新→旧"排序返回**（不得无序），否则前端显示的"当前使用"会错。

### `/api/apk-url`
- **GET 响应**：`{ url }`
- **POST body**：`{ url }` → 响应 `{ ok: true }` 或 `{ error }`

### `/api/download-mode`
- **GET 响应**：`{ mode }`，默认 `"link"`
- **POST body**：`{ mode }` → 响应 `{ ok: true, mode }`
- ★ **mode 的取值**：方案 `:1180` 提到 **`link` / `upload` / `telegram`**

### `/api/template`
- **取值集合**：见 `04-landing/runtime/index_root.html:14` 的 **40 个模板名**
- **默认**：`"vodex"`

## 3 · ★ 鉴权行为（前端已明确实现）

**多数端点在前端有 401 处理**：

```js
const r = await fetch(ADMIN + "/api/stats");
if (r.status === 401) { location.href = ADMIN + "/login"; return; }
```

⇒ **这些端点【需鉴权】**（不应加入 `SKIP_AUTH_PATHS`）。
⇒ **但 `/login` 本身必须匿名可达**（否则无法登录）。

**例外**（`:765` `:790` 只 `if (r.status === 401) return;`，不跳转）：
⇒ 仅"静默失败"，**不代表免鉴权**。
