## 三、★ 关键设计裁决（全部有源码级依据）

### 3.1 ★★ **两侧分前缀**（Owner 裁决 甲）

| 侧 | 前缀 | 端点 |
|---|---|---|
| **落地页侧** | **裸 `/api/`** | template、vodex.html、track/*、pixel-config、apk/download |
| **管理台侧** | **`/mgr-admin-8bcde2021d98/api/`** | template、theme、pixel、download-mode、apk-url、stats、visits、apk/* |

**三级证据**：
1. `双平台整合复刻方案.md:235-247`（注释「**--- 落地页侧 ---**」）
2. `双平台整合复刻方案.md:249-264`（注释「**--- 管理台侧（沿用 pjuyr 的隐蔽前缀）---**」）
3. **`admin_dashboard.html:660`**：`const ADMIN = "/mgr-admin-8bcde2021d98";`（**真实文件**）

### 3.2 ★ **D1-C2 判定为"无需实现"**

**依据**：`04-landing/templates/vodex.html:485-492`（Android 侧模板）**已按既有字段调用**三条 track
（`sid`/`lang`/`url`/`dwell`），与 `landing.js` **1:1 对应** ⇒ Owner 裁的"复用"= **保持现状**。

### 3.3 ★ **D1-C4 作废**

**依据**：方案把它切成 `plugins/android/stats.js`（stats/visits），
但按**前缀分侧**原则，`stats`/`visits` 属**管理台侧** ⇒ **已并入 D1-C5b**。

### 3.4 ★ **管理台鉴权缺口（D1-C1b）**

**发现**：`androidPlugin` 与 `apiPlugin` **并列 `register`**
⇒ `apiPlugin` 内的 `authMiddleware` **不覆盖** `androidPlugin`（**Fastify encapsulation**）。
**⇒ 管理台端点曾**裸奔**（无 token 读写）。**

**修复**：`plugins/android/index.js` 在**自己的 scope 内**再挂一次 `authMiddleware`。

**⇒ 现已 8/8 均 401** ✓
