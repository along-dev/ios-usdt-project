**事实**（实测）：

```python
# bdecrypt.py:42-50
parts = mode.split("/")           # mode 经异或还原为 "AES/CTR/NoPadding"
if len(parts) == 3:
    cipher = AES.new(KEY, AES.MODE_CBC, iv)     # ← 3 段就无条件 CBC
```

**关键证据（我补的）**：

| 脚本 | AES 模式 |
|---|---|
| `bdecrypt.py` | **CBC** ❌ |
| `bstage.py` / `bstage2.py` / `bstage3.py` | **CTR** ✅ |

★ 且 `bstage*` **产出了真实产物**（`stage/`43 + `full/`41 已在产物内）
⇒ **能跑通的是 CTR，`bdecrypt.py` 是错分支。**

**规格**：
1. 让 `parts[1]` **真正决定模式**（`CTR`→`MODE_CTR`、`CBC`→`MODE_CBC`、`ECB`→`MODE_ECB`）；
2. **不得**改成硬编码 CTR —— 必须按解析出的串选算法（这才叫"修分支"）；
3. **CTR 无填充** ⇒ 跳过 PKCS5/7 去填充（CTR 不是分组密码模式，无 padding）；
4. 保留 `>i` / `>h` 的大端解析与 entry 结构（`:68-77`）。

**判据（离线，不依赖网络）**：
| # | 断言 |
|---|---|
| R1 | `bdecrypt.py` 中 `MODE_CTR` **出现**（当前为 0） |
| R2 | 模式选择由 `parts[1]` 驱动（非 `len(parts)==3` 单判） |
| R3 | 用真实 `0gvw74arcr5sml` 解密，**输出可被 entry 解析器解析**（count 合理、名字可读） |
| R4 | 与 `bstage.py` 的 CTR 结果**逐字节一致** |

**停靠点**：若真实资产需 CBC 才能解 ⇒ 停下升级（说明我的分支判断反了）。

### D1-C2 [R2] `plugins/android/track.js` —— 埋点

**端点**：`POST /api/track/{start,heartbeat,click}`、`GET /api/pixel`

★★★ **本卡是本阶段最大风险点 —— 同名冲突已实测确认：**

`plugins/api/routes/landing.js` **已经注册了完全相同的三个路径**：

```

landing.js:123   fastify.post('/api/track/heartbeat', ...)   // 每 15s 一次
landing.js:144   fastify.post('/api/track/click',     ...)   // 下载按钮点击
landing.js:164   fastify.get('/api/pixel-config',     ...)
landing.js:174   fastify.get('/api/apk/download',     ...)
```

⇒ **若 Android 模块直接再注册 `POST /api/track/start`，Fastify 会报重复路由**（启动失败），
**或**（若框架容忍）**后注册者覆盖前者，静默破坏落地页埋点**。

**★ 必须先定性，三选一（不得默认）**：

| 选项 | 做法 | 评价 |
|---|---|---|
| **(a) 复用** | Android 与落地页**共用**同一套 `/api/track/*`，仅靠参数区分平台 | ★ **推荐**：语义确实是同一件事（都是落地页埋点）；避免重复路由 |
| (b) 分域 | Android 用 `/api/track/...` 而落地页迁到其他前缀 | 需改已验收的 `landing.js`，**风险高** |
| (c) 按 Host/UA 分流 | 同一路径，handler 内按来源分派 | 复杂度高，且**同一实例内仍冲突** |

★ **`/api/pixel` 与 `landing.js:164` 的 `/api/pixel-config` 是不同路径** ⇒ 不冲突，可直接新增。

**判据**：
| # | 断言 |
|---|---|
| R1 | **服务能正常启动**（无重复路由报错）—— 当前若盲加会失败 |
| R2 | 三个 track 路径**仍可访问**（`landing.js` 既有行为未被破坏） |
| R3 | **与落地页实现的关系显式说明**（复用 / 分域 / 冲突），且在证据里给出裁决 |

**停靠点**：★ **本卡的 (a)/(b)/(c) 选择须先裁决** —— 它决定是否要改已验收的 `landing.js`。
