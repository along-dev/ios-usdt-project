**★★ 取证（2026-10-02，决策 Agent 提出 + 调度实测确证）**：

```go
// 01-backend-go/core/server.go:48
address := fmt.Sprintf(":%d", global.GVA_CONFIG.System.Addr)   // ★ 用作【端口】(%d)
```

```yaml
# X:\...\_i2c1_ws\config.yaml:136

```

**⟹ ★★ 本清单【先前版本】建议的 `addr: "127.0.0.1"` 是【错误的】**
（**`%d` 无法格式化字符串 ⇒ 会启动失败**）。**该建议已作废。**

**★ 正确的改绑方式（Go 侧）**：

**Go 的 `addr` **只承载端口**，**绑定地址硬编码在 `fmt.Sprintf(":%d", ...)`**
（**`":"` 前无 host ⇒ Go 默认绑全网卡**）**。

⇒ **要用环境变量控制绑定，需改代码**：
```go
// core/server.go（建议改法，★ 未实施）
host := os.Getenv("GVA_BIND_HOST")     // 默认空 = 原行为（全网卡）
address := fmt.Sprintf("%s:%d", host, global.GVA_CONFIG.System.Addr)
```

**★ Node 侧**：`app.js` 的 `fastify.listen({ port, host })` 传 `host: process.env.BIND_HOST || '0.0.0.0'`
（**默认值保持现状 ⇒ 装测环境零改动**）。

**★★ 折中方案（决策 Agent 建议，已在 §七 落地原则）**：
**「默认值 = 当前装测行为；生产值 = 环境变量注入」**
⇒ **装测环境不改一行，生产环境设 `GVA_BIND_HOST=127.0.0.1` / `BIND_HOST=127.0.0.1`。**

**★★ 实施进展（T26 / ①B，2026-10-02）**：

| 项 | 状态 |
|---|---|
| **Node 绑定 host** | ✅ **已实现**（`app.js:327` 读 `BIND_HOST`，**默认 `0.0.0.0` 不变**）<br>★ **反向断言已通过**：设 `BIND_HOST=127.0.0.1` ⇒ `LocalAddress=127.0.0.1`，**LAN `192.168.3.130:3000` 拒绝连接**<br>★ **零退化**：主集仍 **48/48 = 100%** |
| **Go 绑定 host** | ⏸ **留部署期**（决策 Agent 裁定：**收益只在生产兑现，成本在当下**）<br>★★ **关键事实**：**8888 运行的二进制不在源码树内**（`_i2c1_server_t26c.exe`）<br>★ 且**构建区副本与源码树的 `server.go` 字节数不同**（**2010 vs 1334**）<br>⇒ 实现时须**同步两份**：源码树 + `_build_ws_usdt\qianke\core\server.go` |
