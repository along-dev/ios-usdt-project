### 2.2 `DropTable`：白名单 + 存在性校验（`G-09`）

```go
var reSafeTableName = regexp.MustCompile(`^[A-Za-z0-9_]{1,64}$`)

func (autoCodeService *AutoCodeService) DropTable(tableName string) error {
    if !reSafeTableName.MatchString(tableName) { return fmt.Errorf("非法表名: %q", tableName) }
    // SELECT COUNT(*) FROM information_schema.tables WHERE table_schema=DATABASE() AND table_name=?
    if n == 0 { return fmt.Errorf("表不存在: %q", tableName) }
    return global.GVA_DB.Migrator().DropTable(tableName)   // ★ 不再自行拼 SQL
}
```

**为什么用 `Migrator().DropTable` 而不是继续拼串**：`总纲` W-BE-07 的反向断言要求 `DROP TABLE " + tableName` **计数为 0**。
白名单能挡住注入，但字面量仍在 ⇒ 改用 GORM 既有能力（复用优先），既满足断言，也由驱动负责标识符引用。

### 8.2 但**"静默"这个判断是错的** —— 错误在**全局拦截器**里已经弹出来了

`03-web-admin/src/utils/request.js`（**读码取证**）：

| 情形 | 代码位置 | 行为 |
|---|---|---|
| `code != 0`（业务失败，HTTP 200） | `:71-76` | **`ElMessage({type:'error', message: msg})`** |
| `data.reload` 为真 | `:77-81` | 清 token + 跳登录页 |
| 无响应 / 500 / 404 / 其它 | `:85-124` | **`ElMessageBox.confirm("检测到接口错误…")`**，500 还提供"清理缓存" |

**实测印证**（无 token 打受保护端点）：
```
$ curl -s -o - -w "\nHTTP=%{http_code}\n" http://127.0.0.1:8888/device/get_index_info
{"code":7,"data":{"reload":true},"msg":"未登录或非法访问"}
HTTP=200
```
⇒ 前端会**同时**弹 toast（"未登录或非法访问"）**并**登出。**不是静默。**

且 Go 侧失败体里 `data` 恒为**对象**（`{"reload":true}` 或 `{}`），
⇒ 页面里 `agentlist.value = res.data.list` 取到 `undefined`，**不会抛异常**、**不产生未捕获 rejection**。
