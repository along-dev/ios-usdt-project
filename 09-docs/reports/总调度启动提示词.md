1. **基线检查**：确认在 `E:\USDT项目`、工作区无未授权改动。不符 → 停。

   （**无 git，不建分支/工作树**）。★ **`eol` 必须实测**，不得沿用旧值。
4. **`task_branch` 写「无」**
5. **派执行 Agent**：卡片全文 + **副本路径**
   - ★ **一卡一份仓外副本**（必须含 `node_modules` / 运行产物）
   - ★ **必须显式声明**：副本从哪来（源路径 + 取副本时刻 + 关键产物 sha256）
6. **【复核】自己重跑**该卡 verify，取**你自己会话里的真实退出码**，
   与执行者自报**逐位比对**。不一致 → 未通过，退回。
   **取退出码不接管道**：`cmd > /dev/null 2>&1; echo $?`
   （PowerShell 用 `echo "EXIT=$LASTEXITCODE"`）
7. **提交**：**无 git → 提交动作改为「确认副本内容 sha256 + 写入台账」**
8. **派审核 Agent**：R0 不派；R1 派 1 名（可波次末批量 3–5 张）；
   R2 派 **2 名**（**A 审内部 / B 审跨件，互不可见，当场派**）；
   R3 再加 1 名专项（安全/权限）**或按停靠点交 Owner**
9. **处置 Finding**：**P0/P1 → 停下升级 Owner，不自动修订**；
   P2 → 退回重跑第 6、7 步；P3 → 登记不阻断；
   两轮未解 → 逐条裁决记理由；**双审分歧不取并集不取交集，由你裁决留痕**
10. **内容 sha256 一致核对**：**同一内容 sha256 必须在「派审 / 审核 / 批准」三处一致**，
    任一不等报 `BLOCKED_CONTENT_MISMATCH` **不合并**。
    **审核后内容 sha256 变化必须重审。**
11. **合并**：因无 git，**"合并" = 把审过的副本内容采纳为产物**；
    冲突 → 中止进 BLOCKED，**不手工硬解**
12. **台账 + 清理**：追加一行（档位与理由 / 副本来源 / 三处内容 sha256 /
    verify 证据 / Finding 与分歧处置摘要）；写完顺手看台账余量，低于阈值就拆

## 八、怎么连「决策 Agent」

**你连接一个独立的决策 Agent**，用于在**停靠点/需要决策**时产出**可交给 Owner 的建议**。

### 它的职责（**不写代码，不派活**）

对每个决策事项，产出**四段式**：

```
需要决策：<一句话>
建议：<选项 + 为什么>
备选：<每项含代价>
影响范围：<哪些卡/哪些文件/哪些验收项>
不决策时的行为：<维持现状会怎样>
```

### 它的强制约束

- ★ **不得写代码、不得改文件、不得派卡**
- ★ **不得代替 Owner 裁决** —— 它只**推荐**，裁决权在 Owner
- ★ 必须**列出"不决策时的行为"**，让 Owner 能判断"拖着会怎样"
- ★ 建议必须**附证据锚点**（文件:行号），不得凭印象

### 何时喊它

1. 出现 **P0/P1 Finding**
2. 执行者返回 `BLOCKED_CONTRACT`
3. 触及**契约本**任何一条
4. 触及**资金 / 权限 / 部署 / push**
5. 卡内明示的**停靠点**（如 `F1-C6` 的 `/api/` 分流）
6. 双审分歧需裁决时（**你裁决，但要留痕**）

### 何时**不必**喊它

- 常规 P2/P3 Finding 处置（你自己按规则办）
- 波次编排、并行度、副本分发（你的本职）
- 卡内已写明的规格（照做即可）

## 十一、台账行格式（沿用既有）
