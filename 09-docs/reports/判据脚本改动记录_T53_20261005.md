## 二 · 三个洞怎么修的

### `F-T51-A`（**P2**）：`/*!…*/` **版本注释**里的 `USE` 静默放行 —— **收口为「词法级能力口径」**

★ **先自证两条（本件现读）**：
- **引擎侧**（隔离 MySQL 13306 · 只读）：`SELECT 1 /*!50003 + 2 */` ⇒ **3**；对照普通注释 `SELECT 1 /* + 2 */` ⇒ **1**
  ⇒ **版本注释的内容确会被执行**。
- **装置侧**：喂 `/*!50003 USE qk_e2e */;\nALTER TABLE packet DROP COLUMN custom_user_id;` ⇒ **原样放行**（未中和、哨兵未抛错）⇒ 洞成立。
- **真实面**：全 12 件 migration ＋ `schema/qake.sql` 里 `/*!` **零命中** ⇒ **当下触发 ＝ 0**（潜伏）。

**根因**：旧 `_iter_statements` / `_skip_trivia` 把 `/*…*/` **一律当普通块注释整段跳过** ⇒ 起头判定看不到它。

**修法（★ 卡 §二 要求的"口径级"，⛔ 不再逐形态打补丁）** —— 新增**词法层** `_code_mask()`：
> **先逐字符标注「是否属于会被执行的代码」**，**再<ins>只在代码位</ins>按 `;` 分句**，逐句判「**以 `USE` 关键字起头**」。
> - 行注释（`-- ` / `#`）· 块注释（`/* … */`）· 字符串（`'…'` / `"…"`）⇒ **trivia**
> - ★★ **版本注释 `/*!…*/` 与 `/*M!…*/` 的<ins>内容算代码</ins>**（只把 `/*!`＋版本号 与收尾 `*/` 记为 trivia）
> - 反引号标识符**算代码**（库名不得因反引号而隐形）

配套：
- **判定与哨兵都走代码视图**（`_code_view()` 给出「代码串 ＋ 每个字符在原串的偏移」）；
- ★ **最小替换**：命中后**只换库名 token**（带引号者连引号一起换，⛔ 避免生成 `` ``tmp`` ``）⇒ 版本注释**外壳与尾注逐字节保留**：
  `/*!32306 USE qk_e2e */;` ⇒ **`/*!32306 USE \`qk_ad09_check\` */;`**（MariaDB 执行时切到**临时库**，语义保真）；
- **单源**：`hygiene._code_uses()` 改为**直接调** `A.code_level_uses()`（⛔ 本件不另写分句器/判定）；
  `hygiene` 的 `A3` 亦加入**版本注释形态**（证明"继承"而非"各写一套"）。
