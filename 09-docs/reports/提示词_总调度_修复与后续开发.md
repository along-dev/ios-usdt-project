## 五、★ 必看的坑（本项目已踩过）

| # | 坑 |
|---|---|
| **P-5** | **量尺错**：探端点前先取**权威路由清单**（Go 侧 `sys_apis` 表 100 条），**不凭印象拼 URL**；命中 404 先怀疑路径再怀疑服务 |
| **P-1** | 引用断言先贴 **import 的绝对路径**（别把"源目录"成绩记成"产物的"） |
| **P-38** | `vite build` 清 `outDir` ⇒ **并发构建互相破坏** |
| **P-42/P-44** | `Start-Process -RedirectStandardOutput` 起 Node **静默失败**；**冷启动 135s** |
| **P-53** | **"静默兜底 + 静态期望" = 假红/假绿双源**；拿不到真值 ⇒ **SKIP，不得判 PASS** |
| **契约 C-2** | **Go 业务失败也返回 HTTP 200，`code` 在 body**；**Node** 才用真实状态码 ⇒ **别用 HTTP 状态判鉴权** |
| ★ **环境** | 该环境**可能被并行会话共用**（曾实测被拆停六端口、`subst X: /D`）⇒ **运行态读数一律带时点**；引用计数前**当场重测** |
