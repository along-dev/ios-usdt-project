## 四 · ★ 教训（**已登记为 P-56**）

**★★ 在多会话并行改同一仓库时，`git add -A` 会把【别的会话的在途改动】一并提交。**

**★ 正确做法**：
```powershell
# ★ 只提交自己改的文件
git add -- 09-docs/analysis/pjuyr-malware/ 09-docs/reports/文档时效索引.md 09-docs/INDEX.md
# ★ 提交前先看 git status 确认范围
git status --short
```

**★ 配套**：
- **提交前必须 `git status --short` 核对文件清单**；
- **若发现非自己改动的文件 ⇒ 逐个 `git add -- <path>`**，**不用 `-A`**；
- **提交信息应与实际内容一致**（本次不符，**如实声明**）。
