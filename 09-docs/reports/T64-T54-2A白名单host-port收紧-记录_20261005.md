## 二 · 改了什么（★ 逐条 · 只加"守"、不改默认行为）

### 共同点（两件**同一口径**）

在**既有的**库名判定**之后**追加一段 **`host:port` 判定**：

```go
// ★ T64：`host:port` 必须落在**本机** —— ⛔ 非本机一律拒。
host := cfg.Addr
if h, _, e := net.SplitHostPort(cfg.Addr); e == nil {
	host = h
}
switch host {
case "127.0.0.1", "localhost", "::1":
default:
	return fmt.Errorf("白名单外：DSN 主机 = %q（…）", cfg.Addr)
}
```

### 分别的落点

| 件 | 改法 |
|---|---|
| `billing_test.go` | `t54DSNError()` 内**追加** `Addr` 判定（原 `DBName` 判定**原样保留、顺序在前**）；`TestT54_WhiteListGuard` 表驱动**加 `host` 维度**（原 5 例**一字未改**，新增 6 例） |
| `t44_v1_test.go` | ★ `t44Setup` 里原先的**内联库名判定**（`dbName != "qk_e2e_test"` ⇒ `Fatal`）**改为**走新函数 `t44DSNError(dsn)` —— 判定**语义不变**（仍精确等值拒非隔离库），并**新得** `Addr` 判定；新增纯函数测试 `TestT64_T44DSNError_WhiteListGuard` |

★ 新增 `import`：两件各加 `"net"`；`t44_v1_test.go` 另加 `"fmt"` 与 `mysqldrv "github.com/go-sql-driver/mysql"`（该件原本缺这两个）。

### ★★ 一处**判断取舍**（请复核者重点看）

**端口不钉，只钉主机。** 只允许 `127.0.0.1` / `localhost` / `::1`，**不限端口**。

理由：本卡缺陷的**威胁面是"远端主机"**（"那台机器上若恰有同名库，测试会写**它**"）；本机任意端口都不构成"写别人机器"的风险。反之若把端口也钉死到 `13306`，**会误拒本机 3306 的合法隔离库实例**（合规模拟同一风险的"过钉"）。★ 若总调度/复核者认为应按 `13306` 收窄，**改一行常量即可**，但那是**口径变更**、需明示。

★ 另一处**如实披露**：`t44_v1_test.go` 的 `Addr` 由**本件硬编码**（`127.0.0.1:13306`）拼出 ⇒ 该件的 `Addr` 分支**当前不会被 env 触发**。加它是为 ①「两件同口径」② 防将来把 host 参数化。★ 故 `t44` 的 `V1` 只能由**纯函数测试**证明（见 §三）。
