## §1 把 `start:flat` 改成响亮失败

拟改 `02-backend-node/package.json`，**仅这一行**：

```json
"start:flat": "node -e \"console.error('[start:flat] DISABLED: 02-backend-node/src/ is a STALE FLAT COPY (15 forked files, 15 missing modules). Real entry: src_restored/app.js. See src/README-NONAUTHORITATIVE.md'); process.exit(1)\""
```

**三条设计取舍（都不是偏好，是约束）**
1. **用 `node -e` 单命令** —— 不依赖 shell 内建。`type`/`echo` 在 cmd 与 sh 语义不同，跨平台不稳。
2. **消息保持 ASCII** —— 本机 cmd 是 **GBK 代码页**，本项目已记录「GBK 中文 ⇒ 测试假象」。中文直出会 mojibake，反而**不响亮**。⇒ **中文详情放 README，命令行只给 ASCII 一行 + README 路径**。
3. **保留 `start:flat` 这个键**（不删）—— 敲它得到的是一句说明，而不是 `Unknown script`。

## §6 ★ 一个建议先说清的副作用面（关系到 (C) 是否真"两种结局都安全"）

总调度论证 **(C) 在两种结局下都安全** —— 对**运行时**成立。但有**一支未覆盖**：

> **若镜像的构建期（Dockerfile 里）用 `npm run start:flat` 或依赖该键**，本改动会让**构建**失败，而不是运行时失败。

- **好的一面**：同样"当天就炸出真值"；
