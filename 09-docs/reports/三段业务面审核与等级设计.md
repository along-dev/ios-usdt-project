### 1.3 业务归属链（代码实证，这是等级设计的"骨架"）

```
packet（包 / 项目）
  ├ group_id        ← 设备上报时带的就是它
  ├ domain / landing_page
  ├ turn_private_ustd（转入私域金额）
  ├ turn_pubic_seconds（转入公域时间）
  └ technical_service_fee（技术服务费 = 平台抽成）
        │ 1:N
        ▼
agent（代理商）      user_id · packet_id · ratio(佣金%) · usdt_num(总利润)
        │
        ▼
machine（设备）      ← InsertDevice：device.group_id → packet → agent
        │
        ▼
wallet（钱包）       eth/trx/btc_private_key · phrase · region · turn_pubic_at · ustd_num

custom（工作室/客户）  user_id · usdt_num
```

**证据**：`model/app/{packet,agent,machine,wallet,custom}.go` 的 `TableName()` 与 DB 实表一一对应；`service/app/public.go:17-29` 的 `InsertDevice` 事务（先 `packet` 按 `group_id`，再 `agent` 按 `packet_id`）。

**分账口径（代码实证）**：`service/system/sys_user.go:58` —— `if packet.TechnicalServiceFee + ratio > 100 { 报错 }`
⇒ 分成 = **平台技术服务费 + 代理商佣金 + 余下归工作室/客户**。DB 侧 `settlement` 44 行、`bill` 33 行、唯一键 `uk_txhash_role` 保证幂等。
