## 四、★ 两个新增模块（不同于原方案）

### 4.1 `10-sweeper` —— wallet-sweeper

**这是什么**：本地钱包**多链**余额测绘与归集工具，纯 Python + **自实现签名**，无行业 SDK。

**★ 支持 9 条链**（原方案只假设 `eth/tron/btc` 三链）：

| 链 | 资产 |
|---|---|
| ETH / BSC / Polygon / Arbitrum / Base / Optimism | 原生币 + USDT/USDC/DAI/BUSD |
| TRON | TRX + TRC20-USDT |
| Bitcoin | BTC（P2PKH / P2SH-P2WPKH / P2WPKH） |
| Solana | SOL + SPL USDT/USDC |

**方案完全空白的两块能力**：

| 模块 | 能力 |
|---|---|
| `privkey.py` | **私钥 11 种写法变体识别 + 规范化还原**（去重合并 + 来源可追溯） |
| `control.py` | **多签 / 权限转移 / EIP-7702 委托 / gas 可行性检测** |

**★★ 核心洞察：「余额非零 ≠ 能拿走」**

| 类型 | 检测方法 | 真实案例 |
|---|---|---|
| **TRON 权限转移** | `owner_permission` 首个 key ≠ 本地址 | `TUEZSdKso…` 已转至 `TUmdykWX…` |
| **EVM EIP-7702 委托** | 代码为 `0xef0100‖地址` | `0x9858effd…` 委托给 `0x8a67b5…` |
| EVM 多签（Safe） | `getThreshold()` = `0xe75235b8` | — |
| BTC 多签 | `3` 开头（P2SH） | — |
| Solana 托管 | 账户 owner ≠ System Program | — |

> **原方案假设"拿到私钥就能归集"，该工具证明需要前置控制权检测。**

**已验证深度**（README §七）：Solana 自实现序列化**经链上 `simulateTransaction` 实测**
（推进至 `SignatureFailure`，证明结构校验全过）；控制权检测**在真实链上数据命中**。

**★ 但它构成第三条归集路径**（见 §6.8）。

#### A3 详情（原子占位，消除 TOCTOU）

```
gasleak collect 流程：
  1. POST /app/wallet-status { wallet_id }  → 若 progress != 0 则跳过
```

### 6.4 PowerShell 脚本必须带 UTF-8 BOM

**PS 5.1 会把无 BOM 的 UTF-8 当 ANSI(GBK) 读**，中文注释导致伪语法错误：

```
Unexpected token '}' in expression or statement.
The string is missing the terminator: ".
```

→ 新建/修改 `.ps1` 后**必须**确认 `EF BB BF`。
→ **本项目曾因此发生"脚本被截断为 3 字节"的事故**，改前必须备份。
