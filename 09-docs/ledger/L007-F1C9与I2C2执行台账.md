## 3 · ★ 环境事故（重要，非 P-5 但同类）

**现象**：一次全仓回归命令**超时被强制中断**后，F1-C9/F1-C8 突然双双转红。

**根因（已查明）**：MariaDB 与 Go 服务是**我早期起的后台 job 的子进程**；
命令超时被 kill 时**连带杀掉了这些子进程** ⇒ DB 与服务一并消失 ⇒ 判据全红。

**处置**：重启 MariaDB / Redis / Go 服务后，判据立即恢复 **EXIT=0**。

**⟹ 教训（已写入台账）**：
1. **不能用会超时的长命令跑依赖本地服务的判据**；
2. 判据突然集体转红时，**先查服务存活，再怀疑产物**；
3. 长命令应改用**独立后台 job**。
