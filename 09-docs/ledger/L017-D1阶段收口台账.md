## 2 · ★★ D1-C5b 的架构级发现（本轮最重要）

### 现象

D1-C1b 后管理台端点已 401，**但登录页也被 401 拦**：
```
Auth rejected: token blacklisted {"url":"/mgr-admin-8bcde2021d98/login"}
```
⇒ **登录死锁**（用户无法登录）。

### 根因

`authMiddleware` 由 **`fp()`（fastify-plugin）包裹** ⇒
其 `addHook('preHandler')` **不是**落在自己的 `register`，
而是**提升到调用方所在的 scope** ⇒
**同 scope 内【任何时刻】注册的路由（含"先注册"的兄弟）都会吃 401**。

**执行者实测两种直觉写法均失败**（公开路由 401）；
**唯一可行结构**是把 `authMiddleware` + 受保护路由关进**非 fp 的 `async (inner) => {}` 子封装域**。

### 调度独立复核（Node 重启后）

| 路径 | 实测 | 期望 |
|---|---|---|
| `${ADMIN}/login` | **200** | 200 |
| `${ADMIN}/logout` | **200** | 200 |
| `${ADMIN}/api/theme` | **401** | 401 |
| `/api/template` | **200** | 200 |
| `/vodex.html` | **200** | 200 |

**五条全部符合** ✓
