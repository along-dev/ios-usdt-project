```
我观察到 dist 计数：72 → 196 → 196 → ... → 0 → 0 → 0

```

### 根因

**我同时派发了 T19 和 T20**，**两者都改 `03-web-admin` 并各自跑 `vite build`**：
- `vite` 的 `prepareOutDir` **先清空 `outDir` 再写入**，**无锁**
- ⇒ **一个在写、一个在清** ⇒ **`ENOTEMPTY`**
