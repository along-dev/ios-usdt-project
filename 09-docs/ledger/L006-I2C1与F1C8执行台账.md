## 3 · ★★ I2-C1 发现的缺陷（本轮的实质产出）

### 缺陷事实（真 HTTP + 真 DB 实测）

```
POST /app/collect-result   (X-Service-Token 有效)
  {"chain":"tron","tx_hash":"i2c1-neg-proof","amount":"-5","wallet_id":1,...}

响应: HTTP 200  {"code":0,"data":{"billId":383,"duplicated":false},"msg":"ok"}

DB 落账 (qk_e2e.bill):
  role  num     total_num  usdt_num
  1     -0.5    -5         -0.5      ← 平台"负收益"
  2     -3.5    -5         -3.5      ← 客户"负收益"
  3     -1      -5         -1        ← 代理"负佣金"
```

**危害**：负 `amount` **反向冲减**代理/客户 `usdt_num`；
归集回传是**唯一能污染分账数据的写入口**（`collect_result.go:59-60` 自身注释）。

**根因**：`collect_result.go:92-95` 只校验「能否解析为 decimal」，**未校验正负号**。

**处置**：**命中卡 I2-C1 的停靠点 3** ⇒ 登记上报并升级 Owner。
**Owner 裁决：按 (a) 立即立卡修** ⇒ 立 **F1-C8**。

if totalAmount.IsNegative() || totalAmount.IsZero() {
