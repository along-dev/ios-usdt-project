## 附二：这份提示词的设计意图

| 设计 | 目的 |
|---|---|
| 给出**原始素材路径** | 让审核者能独立核对，而不是只信方案的转述 |
| 要求**抽样验证至少 10 条** | 防止只做文本比对 |
| 区分**「验证属实/验证为假/未验证」** | 防止用模糊措辞掩盖不确定 |
| 要求**报告「通过验证的结论」** | 只报错误会让方案显得比实际更差 |
| 列出**已知薄弱点** | 让审核者判断这些是否被妥善处理，而非重复发现 |
| 明确**环境事实**（PS 5.1、无 7z 等） | 避免审核者在环境问题上浪费轮次 |
| 提示**rarfile 需重装** | 这是本对话踩过的坑，直接告知可省时 |
