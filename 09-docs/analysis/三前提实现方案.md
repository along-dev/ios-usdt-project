## 前提 1：签名/侧载 ✅ 有完整脚本

### 1.1 硬约束

```text
CFBundleIdentifier:       com.apple.mobile.MobileHouseArrest
CodeDirectory identifier: com.apple.mobile.MobileHouseArrest
```
两者必须一致，**改了就禁用 MHA 路径**。

### 1.2 `scripts/build_release_ipa.sh`（源码要点）

```zsh
make clean && make package FINALPACKAGE=1
DYLIB="$REPO_ROOT/.theos/obj/FilzaApplySandboxExt.dylib"

unzip -q "$BASE_IPA" -d "$STAGE_ROOT/stage"
APP="$(find "$STAGE_ROOT/stage/Payload" -maxdepth 1 -type d -name '*.app' -print -quit)"

# ★ 强制校验 MHA 身份
BUNDLE_ID="$(plutil -extract CFBundleIdentifier raw -o - "$APP/Info.plist")"
[[ "$BUNDLE_ID" == "com.apple.mobile.MobileHouseArrest" ]] || exit 65

# ★ 要求 base IPA 未签名
codesign -d "$APP" >/dev/null 2>&1 && { echo "base app is signed"; exit 65; }

cp "$DYLIB" "$APP/Frameworks/FilzaApplySandboxExt.dylib"
codesign --remove-signature "$APP/Frameworks/FilzaApplySandboxExt.dylib"

# ★ 剥离 URL scheme（防 canOpenURL: 检测）
plutil -remove CFBundleURLTypes "$APP/Info.plist"

plutil -replace FilzaSlopVersion -string "$FILZASLOP_VERSION" "$APP/Info.plist"
[ -n "$CATALOG" ] && cp "$CATALOG" "$APP/MCMIdentifiers.plist"
zip -qry "$OUTPUT_IPA" Payload
```

**用法**：
```sh
./scripts/build_release_ipa.sh base-unsigned.ipa out.ipa [MCMIdentifiers.plist]
```

**Makefile 关键行**：
```make
TARGET := iphone:clang:latest:15.0     # → minos=15.0
ARCHS = arm64 arm64e                    # → fat 双 slice
FilzaApplySandboxExt_INSTALL_TARGET_PROCESSES = Filza
```

### 1.3 三种失败模式（README）

| 做法 | 结果 |

| 自动生成 Bundle ID | 装得上，**MHA 失效** |

**可行路径**：付费证书 / 链提权后 `ldid` 自签 / LiveContainer 访客。

## 前提 2：内核偏移 —— 修正后的准确答案

### 2.1 ★ 硬版本门禁（`offsets.m:189-193`）

```objc
void offsets_init(void) {
    if (!(SYSTEM_VERSION_GREATER_THAN_OR_EQUAL_TO(@"17.0") &&
          SYSTEM_VERSION_LESS_THAN(@"26.1"))) {
        printf("[-] Only supported offset for iOS/iPadOS 17.0 - 26.0.x\n");
        exit(EXIT_FAILURE);                    // ★ 硬退出
    }
    ...
}
```

**这就是那行 `Only supported offset for iOS/iPadOS 17.0 - 26.0.x` 的出处** ——
我之前是从编译后的 dylib 里提取到这行，现在拿到了源码上下文：
**它是版本门禁，不满足直接 `exit(EXIT_FAILURE)`**。

### 2.2 偏移是硬编码的，不是运行时算的

| 指标 | 实测值 |
|---|---|
| `off_* = 0x...` 硬编码赋值 | **562 处** |
| `patchfinder` / `find_*` 调用 | **0 处** |
| `CPUFAMILY_*` 引用 | 45 处 |
| `SYSTEM_VERSION_GREATER_THAN_OR_EQUAL_TO` 分支 | **9 个** |

**9 个版本阶梯**（源码行号）：

| 行号 | 版本分支 |
|---|---|
| 254 | `>= 17.0` |
| 403 | `>= 17.1` |
| 452 | `>= 17.4` |
| 514 | `>= 18.0` |
| 656 | `>= 18.1` |
| 705 | `>= 18.4` |
| 776 | `>= 18.6` |
| 836 | `>= 26.0` |

样例（`offsets.m:254` 起，注释即版本归属）：

```objc
if (SYSTEM_VERSION_GREATER_THAN_OR_EQUAL_TO(@"17.0")) {
    off_inpcb_inp_list_le_next = 0x20;              // 17.0-17.7.x
    off_inpcb_inp_pcbinfo = 0x38;                   // 17.0-17.7.x
    off_inpcb_inp_socket = 0x40;                    // 17.0-17.7.x
    off_inpcb_inp_depend6_inp6_icmp6filt = 0x150;   // 17.0, 17.1-17.7.x
    off_socket_so_usecount = 0x22c;                 // 17.0, 17.1-17.3.x, 17.4-17.7.x
    ...
```

### 2.3 准确的支持矩阵

| iOS | 门禁 | 偏移阶梯 | 判定 |
|---|---|---|---|
| **15.0 – 16.x** | ❌ 直接 `exit(1)` | — | **不支持** |
| 17.0 | ✅ | `>=17.0` | ✅ |
| 17.1 – 17.3 | ✅ | `>=17.1` | ✅ |
| 17.4 – 17.7 | ✅ | `>=17.4` | ✅ |
| 18.0 | ✅ | `>=18.0` | ✅ |
| 18.1 – 18.3 | ✅ | `>=18.1` | ✅ |
| 18.4 – 18.5 | ✅ | `>=18.4` | ✅ |
| 18.6 – 18.7 | ✅ | `>=18.6` | ✅ |
| 26.0 – 26.0.x | ✅ | `>=26.0` | ✅ |
| **26.1+** | ❌ `exit(1)` | — | **不支持** |

**实测机型**（`offsets.m` 头注释）：
```
iPhone12,8 (iOS 17.0)      iPhone13,1 (iOS 17.6.1)
iPhone15,2 (iOS 17.2.1)    iPad7,11   (18.0)
iPhone14,6 (iOS 18.6.2)    iPhone14,6 (iOS 26.0)
```

### 2.4 CPU 家族覆盖（45 处引用）

源码按 `get_hw_cpufamily()` 分级，覆盖 **A10 到 A19 Pro 全系**：

```objc
bool isA13Above = (cpuFamily == CPUFAMILY_ARM_LIGHTNING_THUNDER ||  // A13
                   cpuFamily == CPUFAMILY_ARM_FIRESTORM_ICESTORM || // A14, M1
                   cpuFamily == CPUFAMILY_ARM_BLIZZARD_AVALANCHE || // A15, M2
                   cpuFamily == CPUFAMILY_ARM_EVEREST_SAWTOOTH ||   // A16
                   cpuFamily == CPUFAMILY_ARM_COLL ||               // A17
                   cpuFamily == CPUFAMILY_ARM_IBIZA ||              // M3
                   cpuFamily == CPUFAMILY_ARM_TUPAI ||              // A18
                   cpuFamily == CPUFAMILY_ARM_TAHITI ||             // A18 Pro
                   cpuFamily == CPUFAMILY_ARM_DONAN ||              // M4
                   cpuFamily == CPUFAMILY_ARM_TILOS ||              // A19
                   cpuFamily == CPUFAMILY_ARM_THERA);               // A19 Pro
```

还区分 `isMSeriesIpad`（iPad M 系芯片）。

### 2.5 结论

**前提 2 的准确表述**：
- 15.0–16.x **确实不支持** —— 但原因是**门禁直接 `exit(1)`**，不是因为缺偏移
- 17.0–26.0.x **有硬编码偏移阶梯**，逐版本覆盖
- **26.1+ 也不支持**

**解法**：
1. 15.0–16.x / 26.1+ → **改用第 3 代（MHA-MCM，不碰内核）**
2. 若要扩展 → **需按新版本补 562 处硬编码偏移中的一个子集**（工作量大，需 KDK 对照）

## 前提 3：LiveContainer ✅ 有完整实现

### 3.1 检测（`MCMFilzaIntegration.m:57-60`）

```objc
BOOL MCMFilzaIsRunningInLiveContainer(void)
{
    const char *home = getenv("LC_HOME_PATH");
    return home && home[0] == '/';
}
```

### 3.2 授权根（`:81-93`）

```objc
for (NSString *path in @[
    MCMAbsoluteEnvironmentPath("LC_HOME_PATH") ?: @"",
    MCMAbsoluteEnvironmentPath("HOME") ?: @"",
    MCMLiveContainerAppGroupPath() ?: @"",
]) if (path.length) [roots addObject:path];
```

App Group 通过 `NSUserDefaults` 的 `lcAppGroupPath` selector 取：

```objc
SEL selector = NSSelectorFromString(@"lcAppGroupPath");
if (![NSUserDefaults.class respondsToSelector:selector]) return nil;
id value = ((id (*)(id, SEL))objc_msgSend)(NSUserDefaults.class, selector);
```

### 3.3 六条兼容链接（`:440-475`）

```objc
NSString *sharedRoot = [MCMLiveContainerAppGroupPath()
    stringByAppendingPathComponent:@"LiveContainer"];
// [LiveContainer] Local Apps / Local App Data / Local App Groups
// [LiveContainer] Shared Apps / Shared App Data / Shared App Groups
```

### 3.4 搭建步骤

1. SideStore/AltStore 以**正常自动 Bundle ID** 装 LiveContainer
2. 下载未签名 FilzaSlop IPA
3. LiveContainer → 加号 → 选 IPA
4. **iOS 26+**：配 JIT-less，从 SideStore/AltStore 导入证书
5. **7 天**内刷新（配额：3 App / 10 App ID / 7 天）

### 3.5 ⚠️ 硬限制

README 原文：

> This mode does **not** provide MobileHouseArrest access. FilzaSlop cannot
> browse or edit containers for App Store apps or other apps installed by iOS.
> **Use this mode only to manage LiveContainer content.**

**走这条路就失去跨 App 容器读取** —— 而这才是工具的核心价值。

## 汇总

| 前提 | 实现 | 状态 |
|---|---|---|
| **1. 签名** | `build_release_ipa.sh` + MHA 身份硬校验 | ✅ 完整脚本 |
| **2. 内核偏移** | **硬编码 562 处 + 9 段版本阶梯 + 17.0–26.0.x 门禁** | ✅ 完整，但 15–16.x/26.1+ 直接 exit |
| **3. LiveContainer** | `LC_HOME_PATH` + 6 条链接 | ✅ 完整，但丢失跨 App 容器 |

**关键结论**：
- 前提 2 的 15.0–16.x **不是"能补偏移"，而是代码里直接 `exit(EXIT_FAILURE)`**
- 前提 2 与 3 都由**第 3 代（MHA-MCM）**绕开 —— 它不碰内核，也不受版本门禁约束
- 代价：第 3 代**丢失内核级能力**，且 LiveContainer 模式下**丢失跨 App 容器访问**
