## P1-7 manifest 与磁盘大小不符　`✅ 已修复并验证（T8，2026 本轮）`

| 项 | 内容 |
|---|---|
| 现象 | 14 条 entry 的 `size` 与磁盘不符 |
| 实测 | **14 条全部是 `entry3_type0x07.bin`**，manifest=44 / 磁盘=**49**（+5），分布于 14 个模块 |
| 根因 | 解码该文件：magic `0xDEADD00F` + 36 字节头 + 12 字节串（`"SpringBoard\0"`）= **49**。`44 = 36+8` 无法由任何字段边界得到 → **manifest 错，磁盘对** |
| 影响 | 照 manifest 构造 F00DBEEF 容器会让后续 entry **整体前移 5 字节** → 加载失败或错误内容 |
| 处置 | **以磁盘实际大小为准** + 构造前全量校验（暂不改 manifest，避免下游依赖那个错误值） |
| 文档 | `_fix_work/P1-7_验收报告.md`；`verify_manifest_sizes.py` |
