# I2-C2 [R1] 覆盖率矩阵：把测试与风险对齐

## 目标

建立**「风险项 ↔ 测试用例」的显式映射**，让"哪些还没测"**永远可见**。

## 背景

原审核报告 §一 元结论（本轮复核**确认仍成立**）：

| 声称 | 实际覆盖 | 漏掉的 |
|---|---|---|
| 端到端 30/30 全绿 | 6 次调用**全是 `chain=eth`** | TRON / BTC 路径**从未被调用** |
| 脱敏 0 命中 | 只对 208 条资产集 | **集外凭据不可见**（已实证） |

⇒ **不是"测试不够多"，是"测试与风险不对齐"。**

## 规格

### (a) 矩阵至少覆盖以下维度

| 维度 | 取值 |
|---|---|
| 链 | `eth` / `tron` / `btc` / `bsc` |
| 归集路径 | gasleak 自动 / 潜客 `Sk()` / `10-sweeper` |
| 记账路径 | `CollectResult`（gasleak 回传）/ `Sk()`（潜客） |
| 桥 | 经 Node 桥 / 直连 Go API |
| region | 0 临时域 / 1 公域 / 2 私域 |
| 结果 | 成功 / 业务失败 / 超时 / 并发冲突 |
| 载荷路由 | coruna / darksword / **空白区 17.3–18.3** |

### (b) 每格必须标注三态

`已覆盖（用例 id）` / **`未覆盖（原因）`** / `不适用（理由）`

★ **不得留空** —— 空单元格**正是本项目反复踩坑的地方**。

### (c) ★ `D-4` 相关格必须显式标注

按 `V0` 裁决 **D-4**，以下必须标为 `未覆盖（真机/真链未授权）`：

- 链上广播正确性
- `10-sweeper` 的 9 链签名
- `11-payment` 的 WASM 路径
- coruna 路径穿越可利用性
- PM2 多 worker 实际取值（★ `F1-C4` 遗留）
- 真机投递（`I1-C3` 遗留）

★ **不得让"没验证"看起来像"已验证"**（`D-4` 明文要求）。

### (d) 校验脚本必须能"抓到新增风险"

`verify_coverage_matrix.py` 应断言矩阵**不含空单元格**，
且**新增的链/路径维度**必须被显式处理（**防将来静默遗漏**）。

## 不在范围

- 不新增测试用例（只做映射与可见性）

## 证据要求

- 矩阵文件本身
- `verify_coverage_matrix.py` 的真实退出码
- ★ **未覆盖项的清单与原因**（这是本卡**最有价值**的产出）

## 停靠点

1. 若发现某维度**无法判定**覆盖与否 ⇒ 停下升级（说明判据不足）
