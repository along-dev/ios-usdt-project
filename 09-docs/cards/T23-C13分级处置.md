## ★★ 规格（**不改载荷的前提下能做的**）

### (1) ★ 加**统一设备侧防护层**（`plugins/c2/guard.js`）

| # | 机制 | 说明 |
|---|---|---|
| **A** | **IP 限频** | **每 IP 每端点**的**令牌桶**（**内存实现**）<br>默认：**60 次/分钟**；**`/taskget` 更严（10 次/分钟）** |
| **B** | ★ **body 大小限制** | **按端点分级**：<br>**遥测/事件 ≤ 64 KB**、**上传 ≤ 8 MB**、**taskresult ≤ 1 MB** |
| **C** | ★ **审计日志** | **高风险端点**（**taskget/taskresult/ip-sync**）**记录 IP + did + 时间** |
| **D** | **可选：来源白名单** | **若 `C2_ALLOWED_IPS` 环境变量已设 ⇒ 只放行该集合**（**默认不设 = 不限制**）|

★ **必须在 `plugins/c2/index.js` 内作为 `preHandler` 或 `addHook` 注册**。
★ **不得影响既有载荷链**（**不能要求凭证**）。

### (2) ★ 加 **`taskresult` 的归属校验**（**高危端点加固**）

**当前**（`task.js:36`）：
```js
const task = await Task.findByIdAndUpdate(taskId, {...});   ← ★ 只按 taskId
```

**改为**：**同时校验 `did` 与 task 的 `deviceId` 一致**，**不一致 ⇒ 拒绝**。
★ **这是防"伪造结果"的关键**，且**不改载荷**（**载荷本来就传 `did`**）。

### (3) ★ 登记 **R-13**

**`残余暴露面登记.md` 加 R-13**：
- **事实**：**C2 控制面 12 端点匿名可达**（**设计上要给设备调**）
- **★ 为何不改**：**载荷侧无凭证机制** ⇒ **加鉴权须同改载荷**（**涉及 `05-ios`**）
- **缓解**：**限频 + body 限制 + 审计日志 + taskresult 归属校验**
- **等级**：🟡 **中**（**已加防护，但无身份鉴别**）
- **后续**：★ **待真机条件成熟** ⇒ **立卡实现设备侧签名**

### (4) ★ 文档化

**在 `02-backend-node/README.md` 说明**：**C2 端点的安全模型**（**匿名 + 防护层**）。
