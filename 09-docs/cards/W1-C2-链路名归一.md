# W1-C2 [R3] 链路名归一 + chain 契约冻结

## 目标

消除 **TRON / BTC 归集静默丢账**。

gasleak 回传 `chain ∈ {eth, tron, btc}`，而潜客 `settlement.chain` 只接受 `trx` / `eth,bsc`
→ `LIKE '%tron%'` **匹配不到任何行** → 三处 settlement 全为 0 → `mkBill` 返回 nil
→ **一条 bill 不写、`billId=0`**，但：

- 事务**照常提交**
- `ReleaseCollectLock` **照常释放占位**
- HTTP **200 + `code:0`**

**链上钱已转出，潜客侧 0 记账，两侧都以为成功了。**

**生产数据已证实**（素材 `E:\潜客\qianke\qianke0301.sql`）：
`settlement.chain ∈ {trx ×4, eth,bsc ×4}`，**完全没有 `btc`**。

## 为什么是 R3

命中「**真高危路径**」（`collect_result.go` 写资金分账）+「**碰契约**」（chain 词表）→ 就高不就低。

## ★ 契约冻结（**已冻结** —— 见 `09-docs/spec/contracts.md` 的 **C-1**；本卡只读，不得改）

| 侧 | 词表 | 动作 |
|---|---|---|
| gasleak → 潜客（**入参**） | `{eth, tron, btc}` | **不变**（是 gasleak 自己的 model 枚举，改了要动它的数据） |
| 潜客内部（settlement / token） | `{eth,bsc, trx}` | **不变**（是后台既有生产数据） |
| **归一发生地** | **Go 侧** | 必须在**所有** settlement / token 查询之前 |
| `btc` | — | **显式失败**（非 0 code + 明确 msg），**不得静默 ok** |

**为何 `btc` 选失败而非归一**：潜客后台**无法登记 BTC 收款地址**
（`api/v1/system/sys_qianke.go` 全文无 `btc`），生产 `settlement` 表也无 btc 行。
**静默丢账比报错更坏。** 为 BTC 新增 settlement 支持属范围扩张，须单独立卡。

## 规格（可判定）

1. 归一发生在 `collect_result.go` 内、**4 处查询之前**：
   system settlement / agent settlement / custom settlement / token（后两者含精确匹配）
2. `tron` → `trx`
3. `eth` → `eth`（**保持不变**）—— `LIKE '%eth%'` 已能命中 `eth,bsc`；
   ★ **不得改成 `eth,bsc`**，否则 `token.chain = 'eth'` 的精确匹配（`Where("chain = ?")`）会破
4. `btc` → 返回 `code != 0`
5. **未在词表内**的 chain → 同样返回 `code != 0`（不得回落默认值）
