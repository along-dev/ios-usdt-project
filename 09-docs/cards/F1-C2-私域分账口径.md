# F1-C2 [R3] `region=2` 私域分账口径不一致

## 目标

让**私域钱包（`wallet.Region == 2`）走 gasleak 归集路径时，记账口径与潜客 `Sk()` 一致**。

## 缺陷事实（本轮实读）

| 位置 | 现状 |
|---|---|
| `collect_result.go` | 全文 grep `Region` → **零命中**（无任何 region 分支） |
| `scan.go:58` | `if wallet.Region != 2 { ...系统/代理/客户三笔... }` —— **有** region 分支 |
| `scan.go:407,414` | `wallet.Region = 2` / `= 1` —— 私域标志确会被写入 |
| 审核报告 §七.3 | 生产 `settlement` 表存在 `user_id=-1` 的 `'private trx'`/`'private'` 行 ⇒ **私域路径确在生产使用，非死代码** |

**后果**：私域钱包经 gasleak 归集 → 被按**公域口径**错记成平台+代理+客户三笔；
而走 `Sk()` 是另一套口径 ⇒ **同一钱包走哪条路径，账不一样**。

## 规格

### (a) ★ 必须先读 `Sk()` 的 else 分支，把口径抄准 —— **不得凭命名猜测**

本卡的正确性**完全取决于**读准 `scan.go:58` 的 `else` 分支。
执行者必须**完整读出**该分支（含 `role=4` 的具体含义、写几笔、金额怎么算），
把口径**逐条写进证据**，**再**动 `collect_result.go`。

### (b) 对齐方式：复制口径，而非抽公共函数

一期铁律「**只整合、不新造**」。抽公共分账函数属**重构**，会同时触碰两条路径 ⇒ **本卡不做**。
本卡只做**口径对齐**（在 `collect_result.go` 内增加与 `Sk()` 等价的 region 分支）。

### (c) 不得改变公域行为

`Region != 2`（0 临时域 / 1 公域）的现有分账**必须逐字节保持**。
★ 这是本卡**最容易改过头**的地方 ⇒ 判据必须含**公域回归用例**（R4）。

## ★ 判据先于实现（判据 9）

| # | 用例 | 断言 | 红态（改前） |
|---|---|---|---|
| R1 | 静态：`collect_result.go` 含 `Region == 2` 分支 | 命中 ≥1 | 命中 **0** ⇒ 红 |
| R2 | 静态：region 分支写在 `mkBill` **之前** | 顺序断言成立 | 不成立 ⇒ 红 |
| R3 | 数值：`Region=2` 时分账笔数与 `Sk()` 口径**相同** | 笔数相等 | 不等 ⇒ 红 |
| R4 | 数值：`Region=0` / `Region=1` 时分账结果**与改前逐值相同** | 全等 | **绿**（防改过头） |

★ **R4 是「防改过头」用例**：改前就该绿；若改后变红 ⇒ 说明**公域被改坏了**。
