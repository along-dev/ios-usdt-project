# T6 [R2] 脚手架裁剪 —— **只删 `example/` + `systemTools/`**（**含后端 seed 同步**）

## ★★★★ T6 执行者的**关键发现**（**它是对的**）

### 我的取证遗漏了**后端菜单 seed**

**`01-backend-go/source/system/menu.go`（99 行）的 `:54-81` 是 28 行 menu seed**，
**其中 14 行硬编码指向 `example/` / `systemTools/`**：

| 行 | `Component` | 前端文件现状 |
|---|---|---|
| `:63` | `view/example/index.vue` | ✅ 存在 |
| `:64-67` | `view/example/{excel,upload,breakpoint,customer}/…` | ✅ 4 个存在 |
| **`:75`** | **`view/example/simpleUploader/simpleUploader`** | ★★ **本就不存在（既有失效）** |
| `:68` | `view/systemTools/index.vue` | ✅ 存在 |
| `:69-71` | `view/systemTools/{autoCode,formCreate,system}/…` | ✅ 3 个存在 |
| `:78-81` | `view/systemTools/{autoCodeAdmin,autoCode,autoPkg,autoPlug}/…` | ✅ 4 个存在 |

**⇒ 14 行中 13 行对应**存在的文件**，1 行（`:75`）**本已失效**。**

### ★ 为何它是**活动 seed**（非死文件）

| 证据 | 内容 |
|---|---|
| `menu.go:16-18` | **`system.RegisterInit(initOrderMenu, &initMenu{})`**（**自动注册**）|
| `menu.go:90-99` | **`DataInserted()` 的判据用 `path = "autoPkg"`**（**`systemTools` 的一行**）|

### ★★★ 为何**构建测不出来**（**关键**）

**`src/utils/asyncRouter.js:1`**：
```js
const modules = import.meta.glob('../view/**/*.vue');
// :20-27  按 component 串在 glob key 集里【字符串精确匹配】
//         缺失时 matchKeys[0] 为 undefined ⇒ 返回 undefined
```

**⇒ 删除后 `npm.cmd run build` 仍会 `EXIT=0`（【V5 假绿】），
但点击这些菜单得到【空白页】。**

**★ 这是 P-1（用假绿当验收）的又一实例。**
