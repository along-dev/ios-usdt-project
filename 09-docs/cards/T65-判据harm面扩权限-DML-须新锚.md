## 六 · ★★ **调度裁定（⌛2026-10-05）—— 权限面降级为登记；本卡只做 DML 面**

> ★ **触发**：★ 执行方按 §三 停止条件上报 —— ★ **本机 `13306` 引擎以 `--skip-grant-tables` 运行**，实测：
> ```
> SHOW VARIABLES LIKE 'skip_grant%'  ⇒ skip_grant_tables = ON
> SHOW GRANTS FOR CURRENT_USER()     ⇒ ERROR 1290（该选项下不能执行本语句）
> mysql.user = 5 行 ／ information_schema.USER_PRIVILEGES = <ins>0 行</ins>   ← 权限表被忽略
> ```
> ⇒ ★★ **本机对「权限面」<无引擎语义可观测**> ⇒ ★ **`V1`/`V2` 结构上不可能满足** ⇒ ★ 停止条件成立 ✓

### 1) ★ 裁定：**采 (A)**
- ★★ **本卡<只做 DML 面**>**（`V3`：`TRUNCATE`/`INSERT`/`UPDATE`/`DELETE`）
- ★★ **权限面（`V1`/`V2`）降级为"<如实登记：本机引擎不支持、不实装**>"** ⇒ ★ **⛔ 不得用形态检测替代**（★ 该判据的哲学是**锚引擎语义**；★ 形态检测**可被静默绕过**，正是它明令禁的）
- ★★ **本节<取代> §四 的 `V1`/`V2` 口径** —— ★ 改后验收面 ＝ **`V3`（DML）＋ `V4`（回归）＋ `V5`（零副作用）** ＋ ★ **`V1`/`V2` 以"登记"交付** ✓
