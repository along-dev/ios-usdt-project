## 一 · 公共约束（**每个审查 Agent 必须遵守**）

### 1.1 立场

- ★★ **只审不改** —— **不得修改任何产物文件**
- ★ **唯一允许写的**：**自己的报告**（**`09-docs/reports/`**）+ **`_fix_work/` 下的临时脚本**
- ★★ **写操作测试**：**只读为主**；**若必须写，须在报告中【显式标注】且【可回滚】**

### 1.2 证据标准

- ★★ **每个问题必须给【可复现证据】**（**命令 + 输出** 或 **文件:行号**）
- ★ **不得只给结论**
- ★ **不确定的写"未验证"**，**不得猜测**
- ★★ **区分**：**已验证事实 / 推断 / 待确认**

### 1.3 严重度分级

| 级 | 含义 |
|---|---|
| **[Blocker]** | **阻断上线**（**数据错误 / 安全漏洞 / 主流程不可用**）|
| **[Major]** | **影响功能**（**页面不可用 / 数据不准**）|
| **[Minor]** | **体验问题**（**空态、提示、样式**）|
| **[Info]** | **建议**（**可改进，不阻断**）|

### 1.4 环境事实（**避免重复踩坑**）

```
★ 本机【无 pwsh】，用 powershell
★ Python: E:\CTF\runtime\python\python.exe（必须先设 $env:PYTHONIOENCODING='utf-8'）
★ Node:   E:\CTF\runtime\node\node.exe（不在 PATH ⇒ 需 $env:PATH 前缀）
★ Go:     E:\ios漏洞\_integration\_fix_work\_toolchain\go\bin\go.exe
★ 服务端口：8888(Go) / 3000(Node) / 8080(代理) / 13306(MariaDB) / 16379(Redis) / 27018(MongoDB)
★ 读文件测 eol/bytes 必须用 open(p,'rb')（P-36）
★ eol 断言用「CRLF 数 + LONE_CR 数不变」（P-37）
★ Start-Process 会因 NO_PROXY/no_proxy 重复键报错 ⇒ 用 cmd /c 显式 PATH（P-30）
★ 判据/脚本放 _fix_work/，【不得进产物】（P-4）
```

## 二 · 产出格式（**统一**）

**每个域产出一份 markdown 报告**，**落在 `09-docs/reports/`**，**含**：

```markdown
# <域> 审核报告

## 0 · 结论摘要
- [Blocker] N 项 / [Major] N 项 / [Minor] N 项 / [Info] N 项
- 一句话结论

## 1 · 问题清单（表）
| # | 严重度 | 问题 | 证据（命令/文件:行号） | 影响 | 修复建议 |

## 2 · 逐条详述
### 问题 1：<标题> [Blocker]
- **现象**：
- **复现**：（确切命令 + 实际输出）
- **根因**：
- **影响**：
- **建议**：

## 3 · 已验证正常的项（表）
| 项 | 验证方式 | 结果 |

## 4 · 未覆盖 / 未验证（**必须写**）
- ...

## 5 · ★ 我这一路为什么可能漏
- （**必须写**：说明本域审核方法本身的局限）
```

## 三 · 调度侧汇总

**5 份报告完成后，调度：**
1. **去重**（**同一根因可能被多域发现**）
2. **定级复核**（**调度可升不可降**）
3. **排序**（**Blocker → Major → Minor**）
4. **逐项立卡派修复**
