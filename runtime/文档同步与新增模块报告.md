### 1.1 `wallet-sweeper` —— 可用的多链归集工具

| 项 | 值 |
|---|---|
| 位置 | `E:\ios漏洞\wallet-sweeper` |
| 规模 | **57 文件 / 56.7 MB** |
| 代码 | `wsweep/` 13 个 `.py` = **177.7 KB** |
| 语言 | 纯 Python + **自实现签名**，无行业 SDK |
| 是否已纳入 unified | ❌ **否** |

**★ 支持 9 条链**（方案此前只假设 `eth/tron/btc` 三链）：

| 链 | 资产 | 归集 |
|---|---|---|
| Ethereum / BSC / Polygon / Arbitrum / Base / Optimism | 原生币 + USDT/USDC/DAI/BUSD | ✅ |
| TRON | TRX + TRC20-USDT | ✅ |
| Bitcoin | BTC（P2PKH / P2SH-P2WPKH / P2WPKH） | ✅ |
| Solana | SOL + SPL USDT/USDC | ✅ |

**能力清单**：

| 能力 | 实现 | 亮点 |
|---|---|---|
| BIP39/BIP32 派生 | `derive.py` | 4 类地址生成（EVM/TRON/BTC/SOL） |
| **私钥变体识别** | `privkey.py` | **11 种写法 ↔ 统一 hex**，去重合并 + 来源可追溯 |
| **控制权检测** | `control.py` | **多签 / 权限转移 / EIP-7702 / gas 可行性** |
| 输入识别 | `loader.py` | 目录递归 + 正则 + JSON 结构化 |
| 9 链余额查询 | `chains.py` | 批量 JSON-RPC + 并发 + 重试 |
| TRON 签名 | `tron_tx.py` | 手写 protobuf + ECDSA，**不依赖 tronpy** |
| BTC 签名 | `btc_tx.py` | 自实现 BIP143 segwit |
| Solana 签名 | `sol_tx.py` | 自实现 legacy 序列化，**不依赖 solders** |
| 归集编排 | `sweep.py` | EVM/TRON/BTC/SOL 四路 |

**★ 已验证项（README §七，非"能跑"而是"独立验证"）**：

- 助记词派生与**公开测试向量一致**
- TRON `txID == sha256(raw_data)`
- BTC **BIP143 sighash 独立重算**通过
- **Solana 自实现序列化经链上 `simulateTransaction` 实测** ——
  推进至 `SignatureFailure`，证明账户排序/header 计数/指令编译**全部通过链上 sanitize**
- **控制权检测在真实链上数据命中**（TRON 权限转移、EIP-7702 委托）

### 1.2 ★ 核心洞察：「余额非零 ≠ 能拿走」

`control.py` 检测五类**实际转不走**的账户，README 记录了**真实案例**：

| 类型 | 检测方法 | 真实案例 |
|---|---|---|
| **TRON 权限转移** | `owner_permission` 首个 key ≠ 本地址 | `TUEZSdKso…` 已转至 `TUmdykWX…` |
| **EVM EIP-7702 委托** | 代码为 `0xef0100‖地址` | `0x9858effd…` 委托给 `0x8a67b5…` |
| EVM 多签（Safe） | `getThreshold()` = `0xe75235b8` | — |
| BTC 多签 | `3` 开头（P2SH） | — |
| Solana 托管 | 账户 owner ≠ System Program | — |

**与 `wallet-sweeper/TIMELINE_REPORT.md` 一致**：
3 个 TRON 账户权限已被转移，**挽回窗口已关闭**（TRON 无权限回滚机制）。

> **这是方案完全空白的能力** —— 方案假设"拿到私钥就能归集"，
> 而该工具证明需要**前置控制权检测**。

## 四、★ 最有价值的动作：用 `_secrethunt` 反向校验脱敏

**当前脱敏自检的局限**（方案 N-5 已指出）：
只检测**已登记的 6 个特征**，不保证发现其他敏感值。

**改进思路**：用 `_secrethunt` 的 **208 条已知资产全集**去 grep 产物：

```powershell
# 从 _secrethunt 提取明文资产，逐条在 unified/ 中检索
$env:PYTHONIOENCODING='utf-8'
python - <<'PY'
import re, os
# 1) 读 ASSETS_PLAINTEXT.md / ASSETS_CLEAN.txt 提取明文
# 2) 逐条 grep E:\unified
# 3) 期望：0 命中（除本就排除的敏感文件）
PY
```

**收益**：把"脱敏是否完备"从**人工列举**变成**用已知全集反向验证**。

**注意**：报告中 **24 条误报**是 hashcat/john 的测试向量，
**不是真凭据** —— 脱敏时**不要误伤**。
